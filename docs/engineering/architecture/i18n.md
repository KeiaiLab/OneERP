# 국제화(i18n)/현지화(l10n)

## 전략

- **한국 우선, 글로벌 확장성 대비**: MVP는 한국(ko-KR) 단일 로케일로 출시하되, 통화/로케일/세금 규칙을 플러그인 구조로 분리하여 후속 국가 확장 시 코드 변경 없이 플러그인 추가만으로 대응한다.

## 범위

- 언어(번역 리소스)
- 통화/환율
- 날짜/시간/타임존
- 세금/회계 로케일(국가별)
- 급여/사회보험 로케일(국가별)

## MVP 로케일: 한국 (ko-KR)

### 언어/로케일

| 항목 | 값 |
|------|-----|
| 기본 언어 | ko-KR |
| 폴백 언어 | en-US |
| 번역 리소스 형식 | JSON (키-값), 네임스페이스별 분리 |

### 통화

| 항목 | 값 |
|------|-----|
| 기본 통화 | KRW (대한민국 원) |
| 소수점 자릿수 | 0 (원 단위 절사) |
| 통화 기호 | ₩ |
| 천 단위 구분자 | 콤마(,) |
| 금액 표시 형식 | ₩1,234,567 |

### 타임존

| 항목 | 값 |
|------|-----|
| 기본 타임존 | Asia/Seoul (KST, UTC+9) |
| 서버 내부 저장 | UTC |
| 표시 변환 | 사용자 로케일 기준 Asia/Seoul |
| 일광절약시간 | 해당 없음 (KST 고정 오프셋) |

### 세금

| 항목 | 값 |
|------|-----|
| 부가가치세(VAT) | 10% (단일 세율) |
| 면세/영세율 | 별도 플래그로 처리 |
| 전자세금계산서 | 국세청 e-Tax 연동 (의무 발행) |
| 세금계산서 형식 | 전자세금계산서 표준 (국세청 XML) |
| 사업자등록번호 | 10자리, Luhn 검증 |

### 회계 기준

| 항목 | 값 |
|------|-----|
| 주 기준 | K-IFRS (한국채택국제회계기준) |
| 보조 기준 | K-GAAP (일반기업회계기준) |
| 회계연도 | 1월~12월 (법인세법 기본) |
| 계정과목 체계 | 한국 표준 계정과목 기반 커스터마이징 |

### 급여/사회보험

| 항목 | 값 |
|------|-----|
| 국민연금 | 기준소득월액의 9% (사용자 4.5% + 근로자 4.5%) |
| 건강보험 | 보수월액의 7.09% (사용자 3.545% + 근로자 3.545%), 장기요양보험 포함 |
| 고용보험 | 근로자 0.9%, 사용자 0.9%~1.65% (기업 규모별 차등) |
| 산재보험 | 업종별 차등 요율 (사용자 전액 부담) |
| 원천징수 | 소득세법 기반 간이세액표 적용 |
| 연말정산 | 연 1회 (익년 2월), 소득공제/세액공제 자동 계산 |
| 급여 지급 주기 | 월 1회 (말일 또는 익월 10일 등 설정 가능) |

## 글로벌 확장 설계

### 플러그인 구조

국가별 로직은 코어와 분리된 플러그인으로 구현한다:

```
plugins/
  locale-kr/          # MVP: 한국
    tax.ts            # VAT 10%, 전자세금계산서
    accounting.ts     # K-IFRS, K-GAAP
    payroll.ts        # 4대보험, 원천징수, 연말정산
    currency.ts       # KRW, 소수점 0자리
  locale-us/          # 확장 예시
    tax.ts            # Sales Tax (주별 차등)
    accounting.ts     # US-GAAP
    payroll.ts        # Federal/State Tax, FICA
    currency.ts       # USD, 소수점 2자리
```

### 플러그인 인터페이스 (설계 방향)

- **TaxPlugin**: 세율 계산, 세금계산서 발행, 신고 데이터 생성
- **AccountingPlugin**: 계정과목 체계, 재무제표 형식, 기간 마감 규칙
- **PayrollPlugin**: 사회보험료 계산, 원천징수 계산, 정산 로직
- **CurrencyPlugin**: 통화 형식, 소수점 처리, 환율 변환

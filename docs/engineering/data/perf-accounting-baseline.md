# accounting 부하 baseline

## 시나리오

- 300 rps × 10분, 분개 쓰기 70% + 원장 조회 30%.
- 마감 작업 중 동시 쓰기 100 rps 병행.

## 측정

| 지표 | 값 |
|---|---:|
| 분개 쓰기 p95 | 190ms |
| 분개 쓰기 p99 | 380ms |
| 원장 조회 p95 | 150ms |
| GL 무결성 체크 | 12s (전 테넌트) |
| RSS | 340MB |

## 임계

- 분개 쓰기 p95 > 218ms: 회귀.
- GL 무결성 > 15s: 인덱스 점검.

## 특이사항

- 마감 동시 쓰기 차단이 p95 를 100ms → 190ms 로 증가시킴 (설계 의도).

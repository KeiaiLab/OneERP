# crm 부하 baseline

## 시나리오

- 120 rps × 10분, 리드/opp 조회 + 관계 그래프 탐색 + 캠페인 발송.

## 측정

| 지표 | 값 |
|---|---:|
| opp 조회 p95 | 95ms |
| 관계 그래프 탐색 p95 | 420ms (최대 3 hop) |
| 캠페인 발송 rate | 500/min (이메일 게이트웨이 의존) |
| 세그먼트 재계산 | 8s (1M 레코드) |

## 임계

- 관계 그래프 p95 > 483ms: 인덱스·cache 점검.
- 세그먼트 재계산 > 15s: 증분 전략.

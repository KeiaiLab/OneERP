# 문서 관리

## 문서 워크벤치
- 문서 목록에서는 `draft_editing`, `pending_review`, `approved_ready_to_publish`, `published_signed` 같은 상태 배지를 본다.
- 상단 요약 카드에서 초안/검토/승인/배포/보존 만료 임박 문서 수를 확인한다.
- 각 행의 권장 액션은 현재 운영자에게 가장 먼저 필요한 조치를 보여준다.

## 보존 정책 워크벤치
- 보존 정책 목록에서는 `mapped_active`, `expiry_review_required`, `system_policy`, `inactive` 같은 상태 배지를 본다.
- 상단 요약 카드에서 활성 정책 수, 연결 분류 수, 만료 임박 문서 수, 폐기 승인 필요 정책 수를 확인한다.
- 정책 상세 `summary`는 연결된 문서 분류 이름, 만료 임박 문서 수, 가장 가까운 만료일, 폐기 결재 필요 여부를 함께 보여준다.
- 시스템 정책이거나 연결된 문서 분류/문서가 남아 있는 정책은 삭제할 수 없다.

## 문서 상세
- 문서 상세 화면은 버전 이력, 공유 현황, 전자서명, 감사 로그 요약을 함께 보여준다.
- 배포 문서에 외부 공유가 남아 있으면 권장 액션이 `review_external_shares`로 표시된다.
- 서명이 없는 배포 문서는 `collect_signature`를 먼저 권장한다.

## 운영 팁
- 체크아웃된 초안은 먼저 체크인한 뒤 제출한다.
- 보존 만료가 30일 이내로 남은 문서는 워크벤치에서 별도 집계된다.
- 외부 링크 공유는 만료일과 다운로드 제한을 반드시 함께 설정한다.

# visual-log story checklists

OneERP 사용자 스토리별 visual-log 캡처 체크리스트 모음이다.

- 정본 카탈로그: `docs/plans/2026-04-17-user-story-execution-catalog-design.md`
- 파일 수: 96
- 저장 위치 규약: `docs/superpowers/visual-log/YYYY-MM-DD/<visual-key>/`

## 공통 캡처 규칙

- 기본 6상태: 정상, 빈 상태, 오류, 로딩, 권한 없음, 모바일
- NOTES.md에는 실행 URL, 사용 브랜치/커밋, 콘솔/네트워크 샘플, 차이 메모를 남긴다.
- before/after 비교가 있으면 상태별 파일을 짝으로 보관한다.
